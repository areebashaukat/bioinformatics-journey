# 🧬 Bioinformatics & Genomic Scripting Portfolio

> A collection of Python scripts developed during my bioinformatics learning journey, focusing on automated sequence analysis, database retrieval, and molecular biology simulations.

---

## 🛠️ What This Script Does
This repository hosts my core implementation of Biopython utilities, covering:
* **Sequence Metrics:** Computes base-pair length and evaluates GC content percentage to determine molecular stability.
* **Molecular Simulation:** Automates the Central Dogma steps—converting DNA sequences into transcribed RNA and translated protein sequences.
* **NCBI Entrez Integration:** Connects programmatically to online databases to fetch reference gene records using official accession IDs (e.g., `NC_000913.3`).
* **GenBank Parsing:** Extracts rich biological annotations, organism metadata, and specific coding sequences (`CDS`) from `.gbk` records.

---

## 💻 Tech Stack
* **Language:** Python 3.x
* **Library:** Biopython (`SeqIO`, `Seq`, `Entrez`)
